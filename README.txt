PHILOSOPHIA — Android starter project

This is an initial Android recreation of the supplied SwiftUI app.
It contains:
- Home, Questions, Philosophies, and Advice tabs
- 10 original life questions and their original reflections/perspectives
- 8 original philosophy entries
- 7 original advice entries
- Dark graphite / near-black styling
- Detail screens and back navigation

OPENING THIS PROJECT
1. Unzip PhilosophiaAndroid.zip.
2. In Android Studio choose File > Open.
3. Select the unzipped folder named PhilosophiaAndroid.
4. Wait for Gradle Sync to finish.
5. If Android Studio asks to install missing SDK components, allow it to install them.
6. Do not delete your existing project; this is a separate copy.

This is a first implementation and has not yet been built or tested on your phone.
The first Gradle sync may need an internet connection to download Android build tools.
